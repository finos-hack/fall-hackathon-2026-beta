# 0013. The name is Interlock

Status: accepted. Source: issue #5 D-C.

## Context

A short name that says "connects the blocks" without saying "standard".

## Decision

"Interlock: a reference implementation for interoperable regulated tokens on Ethereum". "EEA Tokenization Starter Kit" stays as the quickstart's description.

## Consequences

An unrelated web3 project, "Interlock Network", exists: a trademark check is needed before any logo or package name.
