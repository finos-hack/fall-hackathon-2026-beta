# 0007. Keys stay on the server side in the examples

Status: accepted. Source: issue #1 D7.

## Context

Zero setup for a newcomer, and no key in a browser.

## Decision

The console has an "act as" switch; the server holds the quickstart keys. Institutions use the core with their own signers instead (0012).

## Consequences

The console is a demonstration tool, not a custody model.
